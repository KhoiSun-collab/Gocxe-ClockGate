## ✨ Features

- **Workers Management** - Add workers, roles, rates per worker
- **Rates System** - Default R45/hour + Role-based rates + Per-worker override
- **Smart Clock-In/Out** - QR code, offline-first, no internet needed
- **Payroll Reports** - Fortnight / Month end, PDF + CSV export
- **Pairing QR** - Link manager + scanner devices securely (Full version only)
- **POPIA Compliant** - Data stays on device, employer is Responsible Party
- **PWA Ready** - Install as app on phone
